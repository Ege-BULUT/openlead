How this page works
  • Data lives in data/roadmap.json. scripts/roadmap_cli.py render regenerates this page (both the diagram AND the cards) from it. Every mutating command re-renders automatically.
  • The diagram's x-axis is execution order, not calendar time. It draws exactly one node per milestone, evenly spaced, colored by status (done / next / planned). No dates are implied.
  • Keep milestone name short (2-4 words). It has to fit next to its neighbors on the diagram. Put the real detail in description/why, which only show in the cards below.
