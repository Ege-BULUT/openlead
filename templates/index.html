How this workspace fits together

Roadmap→ Task Board→ Agent Memory

The roadmap sets the sequence. Each milestone's work becomes real, tracked tasks on the board. Whoever (or whichever agent) does that work keeps notes in Agent Memory. Read the relevant journal before redoing analysis someone already did.

About this workspace
  • Fully local by default. Nothing here pushes anywhere on its own, that's a decision for you to make explicitly.
  • Roadmap and Task Board are edited through scripts/roadmap_cli.py / scripts/tasks_cli.py / scripts/memory_cli.py, not by hand. See each page's footer for the exact commands.
  • Generated by OpenLead, a portable roadmap/kanban/memory scaffold for AI coding agents.
