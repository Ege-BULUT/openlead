## What this is not

- **Not a hosted product.** There's no backend, no accounts, no sync between machines unless
  you build that yourself, for example by putting the workspace directory in your own git
  repo.
- **Not a replacement for Jira, Linear, or GitHub Issues** on a real team with humans who
  need notifications, permissions, and integrations. It's a lightweight, local, agent-first
  substitute for the narrower case of an agent (or several) needing a durable place to track
  its own work on a project you're driving.

## Where OpenLead itself is headed

Short version: a docs/wiki layer for agents to write up findings in a structured, linkable
form, not just flat journals; multi-project support; a single overview across all your
projects; and a skills manager to show, add, edit, delete, and favorite the skills installed
across your agent setup. Full detail and rationale in
[`ROADMAP.md`](https://github.com/Ege-BULUT/openlead/blob/main/ROADMAP.md) on GitHub.
